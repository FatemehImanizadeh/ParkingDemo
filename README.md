# Parking Generator

**A Rule-Based Generative Grasshopper Plugin for Automated Parking Layout Design**

An intelligent computational design tool developed as part of my Master's thesis in Architectural Technology at Shahid Beheshti University. This plugin automates the generation of optimized parking plans using algorithmic and matrix-based approaches.

## ✨ Features

- **Rule-based & Matrix-driven Generation** — Creates multiple valid parking layouts based on site constraints
- **Multi-criteria Optimization** — Evaluates layouts based on efficiency, accessibility, and design standards
- **Automated Best Option Selection** — Ranks and suggests the best solutions
- **Batch Export** — Automatically exports selected layouts as high-resolution PNG images to custom directories
- **Fully Custom Grasshopper Components** — Developed with object-oriented C#
- **User-Friendly Interface** — Designed for architects and designers with minimal coding experience

## 🛠 Technologies

- **Rhino + Grasshopper**
- **C#** (Object-Oriented Programming)
- **.NET Framework**
- **Visual Studio**

## 📥 Installation

1. Download the latest release (`ParkingGenerator.gha`)
2. Copy the `.gha` file into your Grasshopper Components folder:
   - Usually located at: `C:\Users\YourName\AppData\Roaming\Grasshopper\Libraries\`
3. Restart Rhino / Grasshopper
4. The components will appear under the **Parking Generator** tab

## 📖 How to Use

1. Download the example file in GHFile folder
2. open the file
3. define input parameters
4. run the trigger button to execute options
5. enjoy
> Detailed documentation and example files are available in the `examples/` folder.
